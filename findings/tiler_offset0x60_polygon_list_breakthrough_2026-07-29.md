# TILER_JOB Offset 0x60 Breakthrough & Polygon List Generation

**Date**: 2026-07-29  
**Status**: TILER_JOB completes (`0x1 DONE`) and writes valid polygon list (`start=0x8ef80 end=0x8ef90 diff=16`). Fragment JC still hits `0x58 DATA_INVALID`.

---

## 1. Executive Summary

Previously, the `TILER_JOB` completed with `0x1 DONE` but produced an **all-zeros polygon list** (`start=0x0 end=0x0`). This caused `Atom 2` (Fragment JC) to fault immediately with `0x58 DATA_INVALID_FAULT` when reading the empty polygon list in polygon-list mode (`flags=0x81`).

By reverse engineering vendor captures (`001_atom1_hw_jc.bin` and `001_atom2_hw_jc.bin`), we discovered that on **Valhall v9 (Mali-G77 MC9)**:
1. The **Tiler Context Pointer** is located at **words 24–25 (offset `0x60`)** of the `TILER_JOB` header, not offset `0x38`.
2. Offset `0x78` (words 30–31) holds the 64-bit **Index Buffer Pointer**.
3. Setting offset `0x60` to `gva + OFF_TILER_CTX` enabled the GPU hardware tiler unit to run binning, allocate 64 KiB in the `Tiler Heap`, and write non-zero binned polygon descriptors into the `Tiler Context` struct (`0x0001007c3f171000`).

## 2. Valhall v9 TILER_JOB Struct Layout (256 Bytes)

| Offset | Words | Field Name | Description |
|---|---|---|---|
| `0x000` | 0–3 | Exception / Fault | GPU writeback status |
| `0x010` | 4–7 | Header | `vt[4] = (1u<<0) \| (7u<<1)` (Type 7 = TILER_JOB) |
| `0x020` | 8–11 | Primitive | `vt[8] = 0x38008` (Triangles + Index Type), `vt[11] = 3` (index count) |
| `0x030` | 12 | Instance Count | `vt[12] = 1` |
| `0x034` | 13 | Vertex Count Hint | `vt[13] = 3` |
| `0x038` | 14–15 | Legacy Tiler Ptr | Unused on v9 (kept for backward compatibility) |
| `0x060` | 24–25 | **Tiler Context Ptr** | **`gva + OFF_TILER_CTX`** (Valhall v9 native context location) |
| `0x068` | 26–27 | Scissor | `(fb_w - 1) \| ((fb_h - 1) << 16)` |
| `0x070` | 28–29 | Primitive Size | `float 1.0f` |
| `0x078` | 30–31 | **Index Buffer Ptr** | **`gva + OFF_TRI_INDICES`** (points to `uint16_t indices[3] = {0, 1, 2}`) |
| `0x080` | 32–63 | Draw / Shader Env | Fixed-function Vertex Array + Shader Environment |

## 4. Current Blockers & Fragment JC (`0x58`) State

- `Atom 0: TILER_JOB` -> `0x1 DONE` (Polygon list binned & generated)
- `Atom 1: Cache Flush` -> `0x1 DONE`
- `Atom 2: Fragment JC` -> `0x58 DATA_INVALID_FAULT`

When `Atom 2` (Fragment JC) executes in polygon-list mode (`flags=0x81` or `0x01`), it attempts to parse the polygon list descriptor generated by the Tiler. The Fragment HW returns `0x58 DATA_INVALID`.
